# North Ridge Media - Website
A minimalistic photography portfolio build for North Ridge Media. Photos are organized into groups of events in series.

Live website:
www.northridgemediafinland.com

## Overview
The portfolio presents a set of photographs grouped in series by events or theme. The main design goals are.
- Minimalism: uncluttered design get to the point design. Only required info my the client. No more, no less.
- Photo first: website is built around presenting client works first and foremost.
- Responsive design: website adapts to any screen size, from large monitors to tablets and smartphones.
